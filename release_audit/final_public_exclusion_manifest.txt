# The 41 output roots enumerated in the outputs/ section of .gitignore are
# explicit exceptions to the outputs/** exclusion, together with their
# **/phase_cache/ subdirectories, outputs/examples/smoke_test/, and the two
# output-policy README files. That set is exactly what the public test suite and

# clone failed 181 tests with 97 errors (77 test files) and 19 validator checks,
# because the tests read evidence that .gitignore excluded. The exclusion was
# narrowed so the published artifact verifies itself offline.

# represented by data_manifest.json and docs/data_access.md under the reserved
# Zenodo DOI 10.5281/zenodo.22326883, and are NOT required to run the suite.
